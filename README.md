# Ismail | Cybersecurity Learning Portfolio

A structured record of my cybersecurity studies and authorized hands-on practice. I use this repository to explain concepts, document my reasoning, and track progress over time.

## Scope and principles

- Practice only in environments where I have explicit authorization, such as TryHackMe rooms and CTF labs.
- Focus on understanding the underlying concepts and interpreting evidence, not just collecting commands or answers.
- Keep notes reproducible, concise, and honest about uncertainty and limitations.
- Never publish credentials, tokens, private data, or room flags and target-specific solutions.

## Learning path

Topics will be added as I study and practice them:

1. Networking and Linux foundations
2. Reconnaissance and enumeration
3. Web application security
4. Linux and Windows security fundamentals
5. Reporting, remediation, and professional methodology

## Documentation standard

Each study entry should capture:

- Learning objective and short concept explanation
- Authorized platform or lab context
- Commands used, with the purpose of each important option
- Observations and what the evidence does or does not show
- Lessons learned, limitations, references, and review questions
